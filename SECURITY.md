# Security Policy

## Supported versions

The project is actively maintained on the `main` branch.

## Reporting a vulnerability

Please report security vulnerabilities privately, not in public issues.

Use one of the following:

- GitHub Security Advisories for the repository
- or a direct private contact with the maintainer through GitHub

Include:

- description of the issue
- reproduction steps if available
- affected endpoint, file, or dependency
- any known impact or severity

## Review expectations

We will review and respond as quickly as possible, and will aim to provide a remediation plan when needed.

## Responsible disclosure

Please give maintainers a reasonable opportunity to investigate and fix the issue before public disclosure.
